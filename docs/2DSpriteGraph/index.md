## 概要

2DSpriteGraph は、以下の機能を提供します：

- **ノードベースエディタ** - 直感的なグラフィカルインターフェース
- **スプライト管理** - 複数の画像ファイルを統一的に管理
- **変換・エフェクト処理** - リサイズ、回転、色調変更などの処理
- **アニメーション対応** - フレーム序列の定義と管理
- **メタデータ出力** - JSON形式でのスプライト情報エクスポート

## 主な機能

### スプライトロード

画像ファイルをプロジェクトにインポート：

```
入力ノード
├─ ローカルファイル選択
├─ PNG/JPG対応
└─ メタデータ抽出
```

### 変換処理

スプライトに対する各種変換操作：

```
変換ノード
├─ リサイズ（スケーリング）
├─ 回転（角度指定）
├─ トリミング（領域選択）
├─ フリップ（水平・垂直反転）
└─ 透明度調整
```

### アニメーション定義

フレームシーケンスの作成：

```json
{
  "animations": [
    {
      "name": "walk_right",
      "frames": [0, 1, 2, 3, 2, 1],
      "frameDuration": 100,
      "loop": true
    },
    {
      "name": "attack",
      "frames": [4, 5, 6],
      "frameDuration": 50,
      "loop": false
    }
  ]
}
```

### 出力処理

処理結果のエクスポート：

```
出力ノード
├─ PNG/WebP形式
├─ スプライトシート生成
└─ メタデータJSON出力
```

## 使用例

### シンプルなスプライト処理フロー

```
画像読込 → リサイズ → トリミング → PNG出力
```

### アニメーション付きスプライトシート

```
複数画像読込
    ↓
個別変換
    ↓
アニメーション定義
    ↓
スプライトシート生成
    ↓
JSON + PNG出力
```

### 複雑な変換パイプライン

```
元画像 → 自動トリミング → 拡大縮小 → 色調補正 → 透明化 → 出力
```

## 出力形式

### スプライトシート（PNG）

複数のスプライトを1つの画像にまとめた形式。ゲームエンジンで効率的に処理できます。

### メタデータ（JSON）

```json
{
  "sprites": [
    {
      "name": "player_idle",
      "x": 0,
      "y": 0,
      "width": 64,
      "height": 64,
      "pivotX": 32,
      "pivotY": 32
    }
  ],
  "atlasWidth": 512,
  "atlasHeight": 512
}
```

### アニメーション定義（JSON）

各スプライトのアニメーション情報を記述：

```json
{
  "animations": {
    "player_walk": {
      "frames": ["player_1", "player_2", "player_3"],
      "speed": 10,
      "loop": true
    }
  }
}
```

## ワークフロー

### 基本的な使用フロー

```
1. プロジェクト作成
   ↓
2. スプライト画像をインポート
   ↓
3. ノードグラフを構築
   ↓
4. 各変換・処理を設定
   ↓
5. アニメーション定義（必要に応じて）
   ↓
6. 出力設定
   ↓
7. エクスポート
```

### チームでの使用

```
資産管理者: スプライト整理・メタデータ管理
     ↓
グラフィッカー: ビジュアル調整・変換処理
     ↓
プログラマー: JSON読込・ゲーム実装
     ↓
検証: 動作確認・品質チェック
```

## 推奨される用途

| 用途 | 説明 |
|------|------|
| ゲーム素材管理 | 2Dゲームの全スプライト素材を統一管理 |
| キャラクターセット | 複数のキャラクター表現を効率的に処理 |
| アニメーション作成 | フレームベースのアニメーション定義 |
| 画像最適化 | ゲーム配布用に画像を自動最適化 |
| アセット自動化 | 大量の素材を一括処理・変換 |

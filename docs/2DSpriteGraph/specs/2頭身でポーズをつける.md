## 結論

ポーズをつけたキャラクターを2頭身で生成することは可能です。
ただし、安定したスプライトを生成するには、DWPose の骨格を後から2頭身へ変形するのではなく、次の流れで処理することをおすすめします。

```text
Pose Generator
    ↓
2頭身 Skeleton の生成
    ↓
DWPose / OpenPose PNG
    ↓
ControlNet
    ↓
SDXL
```

ポーズの制御画像を生成する前に、頭・胴体・脚の比率を変更します。

## 方法1：骨格比率を変更する

通常の人体比率を次のように設定すると仮定します。

| 部位 | 頭身比率 |
|------|---------|
| 頭 | 1 |
| 胴体 | 2 |
| 脚 | 4 |
| 合計 | 7頭身 |

これを2頭身へ変更する場合、比率を再計算します。

| 部位 | 7頭身 | 2頭身 |
|------|-------|-------|
| 頭 | 1.0 | 1.0 |
| 胴体 | 2.0 | 0.4 |
| 脚 | 4.0 | 0.6 |
| 合計 | 7.0 | 2.0 |

例えば、通常の骨格長をピクセル単位で設定している場合です。

```json
{
  "head": 120,
  "torso": 240,
  "leg": 480
}
```

2頭身へ変更すると、頭を基準に他の部位を短くします。

```json
{
  "head": 240,
  "torso": 100,
  "leg": 140
}
```

KImageGraph の Pose Asset では、次のような体型比率を指定できます。

```json
{
  "motion": "walk",
  "frame": 3,
  "body_style": {
    "head_ratio": 0.50,
    "torso_ratio": 0.20,
    "leg_ratio": 0.30
  }
}
```

## 方法2：SDXLへ「ちびキャラ」を指示する

SDXL のプロンプトでも、2頭身風の表現を指定できます。

```text
chibi character,
super deformed,
2 heads tall,
big head,
small body
```

この方法は設定が簡単ですが、生成フレームごとに頭の大きさが変わる可能性があります。
歩行、攻撃、ジャンプなど複数フレームで構成するスプライト用途には不向きです。

## 方法3：ポーズ生成段階で2頭身化する（推奨）

Pose Generator で通常の7頭身 Skeleton を作るのではなく、最初から2頭身 Skeleton を出力します。

通常の骨格位置の流れです。

```text
nose
 ↓
neck
 ↓
hip
 ↓
knee
 ↓
ankle
```

2頭身版では、各関節間の距離を短くし、特に首から腰、腰から足首までの距離を縮めます。

通常の例です。

```json
{
  "neck": [512, 180],
  "hip": [512, 420]
}
```

2頭身の例です。

```json
{
  "neck": [512, 180],
  "hip": [512, 260]
}
```

生成対象に共通の2頭身 Skeleton を使用することで、DWPose / OpenPose の制御画像にも同じ体型を維持できます。

## 方法4：体型パラメータ化する（推奨）

各部位の拡大率を個別に指定できるようにすると、複数の頭身を切り替えやすくなります。

```json
{
  "body_type": "chibi",
  "head_scale": 1.8,
  "arm_scale": 0.7,
  "leg_scale": 0.5,
  "torso_scale": 0.6
}
```

Body Normalizer でこのパラメータを処理し、2頭身 Skeleton として出力します。

## まとめ

スプライト生成では、プロンプトだけで2頭身を指定するよりも、Pose Generator の骨格比率を2頭身へ変更する方が安定します。

同じ Body Style をすべてのモーションフレームに適用することで、次の利点があります。

- 歩行・攻撃・ジャンプの各フレームで頭身を統一できる
- キャラクターの体格の揺れを抑えられる
- 後工程でのスプライトサイズ補正を減らせる
- 頭身プリセットを切り替えて量産しやすくなる

## 2頭身の歩行骨格

2頭身スプライトを生成する場合は、まず基準骨格となるTポーズを作り、そこから歩行アニメーションへ展開する方法をおすすめします。

2頭身の一般的な比率は、次のとおりです。

```text
頭     50%
胴体   20%
脚     30%
```

骨格の視覚的な比率では、頭を最も大きくし、脚と胴体の順に短くします。

```text
頭     ★★★★★
脚     ★★★
胴体   ★★
```

### 基準ポーズ

1024 × 1024 のキャンバスを基準にする場合、次の座標から始めます。

```json
{
  "width": 1024,
  "height": 1024
}
```

Skeleton JSON の例です。

```json
{
  "body": {
    "nose": [512, 160],
    "neck": [512, 260],
    "left_shoulder": [440, 280],
    "right_shoulder": [584, 280],
```

### 推奨するPose Generator構成

Pose Generator 内部では、次の順で骨格を処理します。

```text
Base Skeleton
    ↓
Body Style
    ↓
2Head Normalizer
    ↓
Walk Cycle Generator
    ↓
Skeleton Frame
```

この構成により、体型の正規化と歩行モーションの生成を分離でき、頭身を維持したままフレーム数や歩幅を変更できます。

### 2頭身向け歩行の特徴

通常の7頭身と比較すると、2頭身では次の特徴を付けると、かわいらしく見せやすくなります。

```text
歩幅       小さめ
腕振り     大きめ
上下動     少し大きめ
```

おすすめ値の例です。

```json
{
  "head_scale": 2.0,
  "torso_scale": 0.5,
  "leg_scale": 0.6,
  "stride": 60,
  "arm_swing": 45,
  "bounce": 12
}
```

この基準骨格とパラメーターから DWPose / OpenPose PNG を生成すると、RPGツクール風やSDキャラクター風の2頭身歩行アニメーションを作りやすくなります。

## DWPose PNG生成用コード

DWPose / OpenPose 用の制御画像は、Skeleton JSONを読み込み、骨を線、関節を点として描画して生成します。

### 入力

```json
{
  "body": {
    "nose": [512, 160],
    "neck": [512, 260],
    "left_shoulder": [440, 280],
    "right_shoulder": [584, 280],
    "left_elbow": [370, 320],
    "right_elbow": [654, 320],
    "left_wrist": [320, 360],
    "right_wrist": [704, 360],
    "left_hip": [470, 420],
    "right_hip": [554, 420],
    "left_knee": [470, 620],
    "right_knee": [554, 620],
    "left_ankle": [470, 860],
    "right_ankle": [554, 860]
  }
}
```

### 出力

```text
walk_01_pose.png
```

### Python実装

この例では画像処理にPillowを使用します。

```python
from PIL import Image, ImageDraw


BODY_BONES = [
    ("nose", "neck"),
    ("neck", "left_shoulder"),
    ("left_shoulder", "left_elbow"),
    ("left_elbow", "left_wrist"),
    ("neck", "right_shoulder"),
    ("right_shoulder", "right_elbow"),
    ("right_elbow", "right_wrist"),
    ("left_shoulder", "left_hip"),
    ("right_shoulder", "right_hip"),
    ("left_hip", "right_hip"),
    ("left_hip", "left_knee"),
    ("left_knee", "left_ankle"),
    ("right_hip", "right_knee"),
    ("right_knee", "right_ankle"),
]


class DWPoseRenderer:
    def __init__(
        self,
        width=1024,
        height=1024,
        background=(0, 0, 0),
    ):
        self.width = width
        self.height = height
        self.background = background

    def render(self, pose_json, output_path):
        image = Image.new(
            "RGB",
            (self.width, self.height),
            self.background,
        )
        draw = ImageDraw.Draw(image)
        body = pose_json["body"]

        for start, end in BODY_BONES:
            if start not in body or end not in body:
                continue

            draw.line(
                [
                    tuple(body[start]),
                    tuple(body[end]),
                ],
                fill=(255, 255, 0),
                width=8,
            )

        for x, y in body.values():
            draw.ellipse(
                (
                    x - 10,
                    y - 10,
                    x + 10,
                    y + 10,
                ),
                fill=(255, 0, 0),
            )

        image.save(output_path)
```

### 使用例

```python
pose = {
    "body": {
        "nose": [512, 160],
        "neck": [512, 260],
        "left_shoulder": [440, 280],
        "right_shoulder": [584, 280],
        "left_elbow": [370, 320],
        "right_elbow": [654, 320],
        "left_wrist": [320, 360],
        "right_wrist": [704, 360],
        "left_hip": [470, 420],
        "right_hip": [554, 420],
        "left_knee": [470, 620],
        "right_knee": [554, 620],
        "left_ankle": [470, 860],
        "right_ankle": [554, 860],
    }
}

renderer = DWPoseRenderer(
    width=1024,
    height=1024,
)
renderer.render(
    pose,
    "walk_01_pose.png",
)
```

`pose`には、2頭身の基準骨格だけでなく、歩行フレームごとに生成したSkeleton JSONも渡せます。

### 8フレームの一括生成

KImageGraph向けには、DWPoseRendererの前段に2HeadWalkGeneratorを配置します。

```text
2HeadWalkGenerator
    ↓
Skeleton JSON
    ↓
DWPoseRenderer
    ↓
walk_01_pose.png
walk_02_pose.png
...
walk_08_pose.png
```

`stride`、`arm_swing`、`bounce`のパラメーターから8フレームを自動生成し、各フレームのSkeleton JSONをDWPoseRendererへ渡すことで、2頭身歩行アニメーション用の制御画像を一括生成できます。

## DWPose形式の色分けに対応

DWPose / OpenPose系ControlNetで使われる骨格画像では、関節や骨の識別用として部位ごとに異なるカラースキームを使用します。
単色の赤い点と黄の線ではなく、DWPose互換の虹色グラデーションで描画すると、ControlNetの学習分布に近い制御画像を生成できます。

### OpenPose系の色

```python
    (0, 255, 0),
    (0, 255, 85),
    (0, 255, 170),
    (0, 255, 255),
    (0, 170, 255),
    (0, 85, 255),
    (0, 0, 255),
    (85, 0, 255),
    (170, 0, 255),
    (255, 0, 255),
    (255, 0, 170),
    (255, 0, 85),
]
```

## 全身版の完成コード

以下は、Body、Face、左右の手、左右の足を描画するDWPose / OpenPose互換の全身Rendererです。
OpenPose風レインボーカラーと黒背景を使用し、ControlNetへ入力するPNGを生成します。

### Skeleton JSON対応範囲

```text
Body
Face
Left Hand
Right Hand
Left Foot
Right Foot
```

各部位のデータがない場合は、その部分を描画せず、存在する部位だけを出力します。

### 完成版実装

```python
from PIL import Image, ImageDraw


POSE_COLORS = [
    (255, 0, 0),
    (255, 85, 0),
    (255, 170, 0),
    (255, 255, 0),
    (170, 255, 0),
    (85, 255, 0),
    (0, 255, 0),
    (0, 255, 85),
    (0, 255, 170),
    (0, 255, 255),
    (0, 170, 255),
    (0, 85, 255),
    (0, 0, 255),
    (85, 0, 255),
    (170, 0, 255),
    (255, 0, 255),
    (255, 0, 170),
    (255, 0, 85),
]

BODY_BONES = [
    ("nose", "neck"),
    ("neck", "right_shoulder"),
    ("right_shoulder", "right_elbow"),
    ("right_elbow", "right_wrist"),
    ("neck", "left_shoulder"),
    ("left_shoulder", "left_elbow"),
    ("left_elbow", "left_wrist"),
    ("neck", "right_hip"),
    ("right_hip", "right_knee"),
    ("right_knee", "right_ankle"),
    ("neck", "left_hip"),
    ("left_hip", "left_knee"),
    ("left_knee", "left_ankle"),
    ("left_hip", "right_hip"),
]

HAND_BONES = [
    ("wrist", "thumb1"),
    ("thumb1", "thumb2"),
    ("thumb2", "thumb3"),
    ("thumb3", "thumb4"),
    ("wrist", "index1"),
    ("index1", "index2"),
    ("index2", "index3"),
    ("index3", "index4"),
    ("wrist", "middle1"),
    ("middle1", "middle2"),
    ("middle2", "middle3"),
    ("middle3", "middle4"),
    ("wrist", "ring1"),
    ("ring1", "ring2"),
    ("ring2", "ring3"),
    ("ring3", "ring4"),
    ("wrist", "pinky1"),
    ("pinky1", "pinky2"),
    ("pinky2", "pinky3"),
    ("pinky3", "pinky4"),
]

FOOT_BONES = [
    ("heel", "inner"),
    ("inner", "toe"),
]


class DWPoseRenderer:
    def __init__(
        self,
        width=1024,
        height=1024,
        background=(0, 0, 0),
    ):
        self.width = width
        self.height = height
        self.background = background

    def render(self, pose_data, output_path):
        image = Image.new(
            "RGB",
            (self.width, self.height),
            self.background,
        )
        draw = ImageDraw.Draw(image)

        self._draw_body(draw, pose_data.get("body", {}))
        self._draw_face(draw, pose_data.get("face", {}))
        self._draw_hand(draw, pose_data.get("left_hand", {}))
        self._draw_hand(draw, pose_data.get("right_hand", {}))
        self._draw_foot(draw, pose_data.get("left_foot", {}))
        self._draw_foot(draw, pose_data.get("right_foot", {}))

        image.save(output_path)

    def _draw_body(self, draw, body):
        for index, (start, end) in enumerate(BODY_BONES):
            if start not in body or end not in body:
                continue

            draw.line(
                [tuple(body[start]), tuple(body[end])],
                fill=POSE_COLORS[index % len(POSE_COLORS)],
                width=8,
            )

        for index, point in enumerate(body.values()):
            self._draw_joint(
                draw,
                point,
                radius=8,
                color=POSE_COLORS[index % len(POSE_COLORS)],
            )

    def _draw_face(self, draw, face):
        for point in face.values():
            self._draw_joint(
                draw,
                point,
                radius=3,
                color=(0, 128, 255),
            )

    def _draw_hand(self, draw, hand):
        for index, (start, end) in enumerate(HAND_BONES):
            if start not in hand or end not in hand:
                continue

            draw.line(
                [tuple(hand[start]), tuple(hand[end])],
                fill=POSE_COLORS[index % len(POSE_COLORS)],
                width=3,
            )

        for index, point in enumerate(hand.values()):
            self._draw_joint(
                draw,
                point,
                radius=3,
                color=POSE_COLORS[index % len(POSE_COLORS)],
            )

    def _draw_foot(self, draw, foot):
        foot_color = (255, 0, 255)

        for start, end in FOOT_BONES:
            if start not in foot or end not in foot:
                continue

            draw.line(
                [tuple(foot[start]), tuple(foot[end])],
                fill=foot_color,
                width=4,
            )

        for point in foot.values():
            self._draw_joint(
                draw,
                point,
                radius=4,
                color=foot_color,
            )

    @staticmethod
    def _draw_joint(draw, point, radius, color):
        x, y = point
        draw.ellipse(
            (
                x - radius,
                y - radius,
                x + radius,
                y + radius,
            ),
            fill=color,
        )
```

### ChibiWalkGeneratorとの連携

完成版Rendererの前段に`ChibiWalkGenerator`を追加すると、2頭身歩行8フレームを自動出力できます。

```text
2Head Walk Parameters
    ↓
ChibiWalkGenerator
    ↓
Full Skeleton JSON × 8
    ↓
DWPoseRenderer
    ↓
walk_01.png
...
walk_08.png
```

この構成により、`stride`、`arm_swing`、`bounce`から歩行骨格を生成し、各フレームをDWPose / OpenPose互換のControlNet入力画像として一括出力できます。

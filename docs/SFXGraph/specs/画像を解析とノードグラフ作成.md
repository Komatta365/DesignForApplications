# 画像を解析とノードグラフ作成

## 概要

**画像→イベント→Copilot→ノードグラフ→SE生成**の5段階パイプラインにより、ゲーム内のビジュアルエフェクト（VFX）から自動的にサウンドエフェクト（SFX）ノードグラフを生成します。

```text
画像入力
  ↓
[1] Vision解析（画像から意味抽出）
  ↓
[2] イベント変換（意味→イベントリスト）
  ↓
[3] Copilot CLI（イベント→ノードグラフ）
  ↓
[4] Graph検証・最適化（Rust）
  ↓
[5] SE波形生成
```

---

## ステップ1：Vision解析ノード

画像からシーン、オブジェクト、アクションなどの意味情報を抽出します。

### 候補モデル

| モデル | 特徴 | 推奨度 |
|--------|------|--------|
| **GPT-4o Vision** | 高精度、コンテキスト理解 | ⭐⭐⭐⭐⭐ |
| **Florence2** | 軽量、ローカル実行可 | ⭐⭐⭐⭐ |
| **CLIP** | 高速、汎用 | ⭐⭐⭐ |
| **YOLO** | オブジェクト検出のみ | ⭐⭐ |

### 出力例

```json
{
  "scene": "forest",
  "weather": "rain",
  "objects": [
    "girl",
    "tree",
    "river"
  ],
  "action": "running",
  "mood": "tense"
}
```

---

## ステップ2：イベント変換（重要）

Vision出力をそのままSE生成すると不安定です。**中間表現として「イベントリスト」に変換**します。

### 変換ロジック

```text
Vision出力（scene, weather, objects, action）
         ↓
イベント推定エンジン
         ↓
イベントリスト生成
```

### 出力例

```json
{
  "events": [
    "footstep_grass",
    "river_stream",
    "rain_heavy",
    "breathing_fast"
  ]
}
```

### イベント定義テーブル

| イベント | 対応する音 | 例 |
|---------|-----------|-----|
| `footstep_grass` | 草を踏む音 | ふしゃッ |
| `river_stream` | 川の流れ | ざあああ |
| `rain_heavy` | 大雨 | ぱあぱあぱあ |
| `breathing_fast` | 息切れ | ぷはあぷはあ |
| `wind_strong` | 強風 | ひゅあああ |
| `sword_slash` | 剣を振る音 | しゅっ |
| `explosion_large` | 大爆発 | どおおん |

### Python実装例

```python
def extract_events(vision_output: Dict) -> List[str]:
    """
    Vision解析結果 → イベントリスト
    """
    events = []
    
    # シーン＋アクションからイベント推定
    if vision_output.get("action") == "running":
        surface = vision_output.get("scene", "default")
        events.append(f"footstep_{surface}")
    
    if vision_output.get("weather") == "rain":
        intensity = vision_output.get("weather_intensity", "medium")
        events.append(f"rain_{intensity}")
    
    for obj in vision_output.get("objects", []):
        if "river" in obj or "water" in obj:
            events.append("river_stream")
        elif "wind" in obj or "storm" in obj:
            events.append("wind_strong")
    
    if vision_output.get("mood") == "tense":
        events.append("breathing_fast")
    
    return list(set(events))  # 重複除去
```

## ステップ3：Copilot CLI へ入力

Copilotは**「イベント → ノードグラフJSON」の変換のみ**を担当します。

### プロンプト構造

```text
Create a sound effect node graph.

Events:
- footstep_grass
- rain_heavy
- river_stream
- breathing_fast

Output JSON only.

Available Nodes:
- NoiseGenerator
- Oscillator
- Envelope
- Filter
- Mixer
- LFO
- Delay
- Reverb
- Gain
- Output

JSON Schema:
{
  "nodes": [],
  "connections": []
}

Generate a valid graph following the schema.
```

### Copilot CLI 実装例

```bash
#!/bin/bash

EVENTS="footstep_grass,rain_heavy,river_stream"
PROMPT="Create SFX graph for events: $EVENTS. Output JSON only."

copilot_response=$(gh copilot suggest "$PROMPT" -t shell)
echo "$copilot_response" | grep -oP '\{.*\}' > graph.json
```

## ステップ5：Graph Schema を固定する（重要）

Copilotに自由回答させると壊れます。**必ずJSON Schema を提供**します。

### Schema定義

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "type": "object",
  "properties": {
    "nodes": {
      "type": "array",
      "items": {
        "type": "object",
        "properties": {
          "id": { "type": "string" },
          "type": { "type": "string", "enum": [
            "NoiseGenerator",
            "Oscillator",
            "Envelope",
            "Filter",
            "Mixer",
            "LFO",
            "Delay",
            "Reverb",
            "Gain",
            "Output"
          ]},
          "params": { "type": "object" }
        },
        "required": ["id", "type"]
      }
    },
    "connections": {
      "type": "array",
      "items": {
        "type": "array",
        "items": { "type": "string" },
        "minItems": 2,
        "maxItems": 2
      }
    }
  },
  "required": ["nodes", "connections"]
}
```

## ステップ6：Rust で検証

Copilot出力をそのまま使わない。**Rustで型チェック・検証**します。

```rust
#[derive(Deserialize)]
struct SFXNode {
    id: String,
    #[serde(rename = "type")]
    node_type: String,
    params: Option<serde_json::Value>,
}

#[derive(Deserialize)]
struct SFXGraph {
    nodes: Vec<SFXNode>,
    connections: Vec<[String; 2]>,
}

fn validate_graph(graph_json: &str) -> Result<SFXGraph, Box<dyn std::error::Error>> {
    let graph: SFXGraph = serde_json::from_str(graph_json)?;
    
    for node in &graph.nodes {
        match node.node_type.as_str() {
            "NoiseGenerator" | "Oscillator" | "Envelope" | 
            "Filter" | "Mixer" | "LFO" | "Delay" | 
            "Reverb" | "Gain" | "Output" => {},
            _ => return Err(format!("Invalid node type: {}", node.node_type).into()),
        }
    }
    
    // 接続の妥当性チェック
    for [from, to] in &graph.connections {
        if !graph.nodes.iter().any(|n| &n.id == from) {
            return Err(format!("Connection source not found: {}", from).into());
        }
        if !graph.nodes.iter().any(|n| &n.id == to) {
            return Err(format!("Connection target not found: {}", to).into());
        }
    }
    
    Ok(graph)
}
```

## ステップ8：推奨ノード構成

Copilotが生成できるノード。**初期段階ではこれだけに絞る**と安定：

```text
入力系：
  - NoiseGenerator（白色、ピンク、ブラウン）
  - Oscillator（波形生成）

制御系：
  - Envelope（ADSR）
  - LFO（低周波振動）

処理系：
  - Filter（ハイパス、ローパス、バンドパス）
  - Gain（音量）

合成系：
  - Mixer（複数入力を混ぜる）

エフェクト系：
  - Delay（遅延）
  - Reverb（残響）

出力系：
  - Output（最終出力）
```

## 最終パイプライン（Tauri + Rust構成）

```
フロントエンド（React）
  ↓
[1] 画像選択 → Vision API へ送信
  ↓
Rust バックエンド
  ↓
[2] Vision結果 → イベント変換（Rust）
  ↓
[3] イベント → Copilot CLI プロンプト生成
  ↓
GitHub Copilot CLI 実行
  ↓
[4] JSON 出力 → Rust で検証・最適化
  ↓
[5] ノードグラフ → SE 波形生成（WebAudio API or Rust）
  ↓
フロントエンド に結果表示
```

## 実装上の利点

| 利点 | 説明 |
|-----|------|
| **安定性** | Copilot の役割を「グラフ設計」に限定 |
| **柔軟性** | イベント DB やテンプレート DB で微調整可能 |
| **検証** | Rust による型チェック・接続検証 |
| **スケール** | 新しいイベントを DB に追加するだけ |
| **再利用性** | テンプレート DB をプロジェクト間で共有 |

---

## まとめ

5段階パイプラインにより：

1. **Vision 解析** で画像から意味抽出
2. **イベント変換** で中間表現を安定化
3. **Copilot** で「グラフ設計」のみ実施
4. **Rust 検証** で出力を型安全化
5. **SE 生成** で最終的な波形生成

この構成により、**安定性・拡張性・保守性**を兼ね備えた自動 SFX 生成システムが実現します。
